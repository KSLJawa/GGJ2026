
#### 1. SideView Kit API (侧视角)

**核心控制器：`SideViewController`** (挂载在玩家身上)

|方法签名 (API)|功能描述|参数说明|调用场景 / 示例|
|---|---|---|---|
|`Move(Vector2 input)`|处理水平移动输入|`input`: 来自 InputSystem 的 Vector2 (通常只用 x)|`Update` 中每帧调用：`controller.Move(input.Move);`|
|`Jump()`|触发跳跃逻辑|无|按下跳跃键时调用。内部已处理土狼时间和跳跃缓冲。|
|`Dash()`|触发冲刺逻辑|无|按下冲刺键调用。会自动处理无敌帧和冷却。|
|`TakeDamage(DamageData data)`|玩家受击处理|`data`: 包含伤害值、击退方向的结构体|敌人攻击判定碰撞时调用。会自动扣血、播动画、触发受击事件。|
|`SetControlEnabled(bool)`|锁定/解锁玩家输入|`true`: 解锁, `false`: 锁定|打开 UI 面板、播放剧情、死亡时调用 `SetControlEnabled(false)`。|

**手感配置数据：`PlayerSideViewData`** (ScriptableObject，给策划调参用)

|字段名|类型|策划配置指南 / 推荐范围|
|---|---|---|
|`moveSpeed`|float|基础移动速度。推荐 `4.0 ~ 6.0`|
|`jumpForce`|float|跳跃初始力度。推荐 `10.0 ~ 15.0`|
|`coyoteTime`|float|土狼时间(离开边缘后仍可跳跃的时间)。推荐 `0.1 ~ 0.2` 秒|
|`jumpBufferTime`|float|跳跃缓冲(落地前按跳跃的缓存时间)。推荐 `0.1 ~ 0.15` 秒|
|`fallGravityMult`|float|下落时的重力倍数(让跳跃更干脆)。推荐 `2.5 ~ 4.0`|

#### 2. TopDown Kit API (俯视角)

**核心控制器：`TopDownController`** (挂载在玩家身上)

|方法签名 (API)|功能描述|参数说明|调用场景 / 示例|
|---|---|---|---|
|`Move(Vector2 input)`|处理 8 方向移动|`input`: 来自 InputSystem 的 Vector2 (x, y)|`Update` / `FixedUpdate` 中调用，内部处理归一化防斜向加速。|
|`SetFacing(Vector2 dir)`|更新玩家朝向/动画|`dir`: 移动方向或鼠标/右摇杆方向|移动时调用，或者停止时保持最后朝向。|
|`Interact()`|尝试与前方物体交互|无|按下交互键调用。内部会自动检测前方 `IInteractable` 并触发。|
|`UseTool(int toolId)`|使用工具/攻击|`toolId`: 工具/武器索引|按下鼠标左键或攻击键调用。|
|`TakeDamage(DamageData data)`|玩家受击处理|`data`: 伤害数据结构体|触碰敌人或陷阱时调用。|

**交互接口：`IInteractable`** (所有可交互物体必须实现)

```csharp
public interface IInteractable
{
    // 返回交互提示文本，如 "按 E 打开"
    string GetInteractionPrompt(); 
    
    // 执行交互逻辑
    void Interact(GameObject interactor); 
}
```

**手感配置数据：`PlayerTopDownData`** (ScriptableObject)

|字段名|类型|策划配置指南 / 推荐范围|
|---|---|---|
|`moveSpeed`|float|移动速度。俯视角推荐 `3.0 ~ 5.0`|
|`interactRange`|float|交互检测距离。推荐 `0.8 ~ 1.2`|
|`interactRadius`|float|交互检测半径(OverlapCircle)。推荐 `0.3 ~ 0.5`|
|`stopDeceleration`|float|松开按键后的减速时间。推荐 `0.0` (像素风通常要求立刻停止)|

#### 3. 通用核心 API (两个 Kit 共享)

**事件中心：`EventManager`** (静态类或单例)

|事件名|触发时机|典型监听者|
|---|---|---|
|`OnPlayerHealthChanged(int current, int max)`|玩家血量变化|UI 血条|
|`OnPlayerDeath()`|玩家死亡|GameManager (触发GameOver), Audio (播死亡音效)|
|`OnInteractionEnter(IInteractable target)`|玩家进入可交互范围|UI (显示提示文本)|
|`OnInteractionExit()`|玩家离开可交互范围|UI (隐藏提示文本)|

**场景与状态管理：`GameManager`**

|方法签名 (API)|功能描述|
|---|---|
|`StartGame()`|加载游戏场景，初始化状态|
|`PauseGame()`|设置 `Time.timeScale = 0`，打开暂停UI，禁用玩家输入|
|`ResumeGame()`|恢复 `Time.timeScale = 1`，关闭UI，恢复输入|
|`GameOver(bool isWin)`|触发结算逻辑，打开结算UI|
