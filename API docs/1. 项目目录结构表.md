## 项目总览

主要目录：

Assets/
├── Core/                     # 底层框架，比赛期间尽量不改
│   ├── Managers/             # 单例管理器 (Game, Audio, Scene, Pool, Save)
│   ├── Events/               # 全局事件中心、EventChannel
│   ├── Interfaces/           # 核心接口 (IDamageable, IInteractable)
│   ├── Utils/                # 扩展方法、数学工具、单例基类
│   └── Settings/             # URP配置、Input System配置、Tag/Layer/物理矩阵
│
├── Kits/                     # 视角套件，比赛时二选一启用
│   ├── SideViewKit/          # 侧视角/平台跳跃套件
│   │   ├── Scripts/          # 侧视控制器、状态机、2D相机
│   │   ├── Prefabs/          # 侧视玩家、测试敌人、地形块
│   │   └── Scenes/           # 侧视白模测试关卡
│   └── TopDownKit/           # 俯视角套件
│       ├── Scripts/          # 俯视控制器、交互检测、8向动画
│       ├── Prefabs/          # 俯视玩家、测试NPC、交互物
│       └── Scenes/           # 俯视白模测试关卡
│
├── _Game/                    # 具体游戏的业务逻辑和内容
│   ├── Scripts/              # 比赛时写的具体玩法逻辑 (敌人AI、武器)
│   ├── Art/                  # 美术资产 (Sprite, 动画, Tilemap)
│   ├── Audio/                # 音频资产 (BGM, SFX)
│   ├── Data/                 # ScriptableObject 数据表 (关卡、敌人、物品)
│   ├── Prefabs/              # 比赛时制作的具体 Prefab (Boss, 特定道具)
│   └── Scenes/               # 比赛时搭建的实际关卡场景
│
├── UI/                       # 通用 UI 框架与预制体
│   ├── Scripts/              # UI 管理器、面板基类、UI 组件
│   ├── Prefabs/              # Canvas, 各种 Panel, 按钮, 血条
│   └── Sprites/              # UI 图集、像素字体
│
├── VFX/                      # 通用视觉特效 (命中、死亡、拾取)
│
└── Plugins/                  # 第三方插件 (DOTween, TextMeshPro 等)
